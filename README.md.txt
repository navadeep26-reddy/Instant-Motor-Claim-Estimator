# 🚗 AI Car Damage Pre-Approval System

## 📌 Project Overview
This is a responsive web application that simulates an AI-based car damage detection and cost estimation system.

Users can:
- Upload car damage images
- Get instant damage type prediction
- View estimated repair cost
- Track claim history

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Design

## 📱 Features
- Image preview before analysis
- Simulated AI damage detection
- Cost estimation logic
- Claim history tracking
- Fully responsive design

## 🚀 How to Run
1. Download or clone the repository
2. Open `index.html` in your browser
3. Upload an image and analyze
